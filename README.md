# Visual Routines

Visual Routines is a local-first Android application that presents calm,
visual step-by-step routines. It is designed for general everyday use and for
people who benefit from reduced cognitive load.

## What is coming

This public repository has been reserved for the reviewed Visual Routines
source release and its ongoing community development. The first source
snapshot is still being prepared and audited.

The published project is expected to include:

- buildable Android application source and tests;
- build, accessibility, privacy, and security documentation;
- contribution and community-maintenance guidance;
- `GPL-3.0-or-later` licensing and image-asset provenance; and
- metadata for an intended F-Droid release.

## Current status

No application source release or APK is available from this repository yet.
This placeholder is not a release announcement and the app is not yet listed
on F-Droid.

The existing private development archive will remain separate. Public source
will be added from a clean, reviewed snapshot without publishing private
operational history or local development material.

## Community

After the reviewed source is published, this repository is intended to become
the canonical place for community discussion, issues, pull requests, and
continued development. Contribution, conduct, security, and maintainer
expectations will be published with that source snapshot.
